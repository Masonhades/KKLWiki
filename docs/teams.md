# 🛡️ Команды и Союзы

Команды и союзы - это основная социальная система сервера.
Игроки могут объединяться в команды, а команды - в союзы для совместного развития, захвата точек интереса и участия в событиях.
Каждая команда имеет владельца, участников и список привязанных точек. Союзы объединяют несколько команд для общего доступа к ресурсам.

---

## 📌 Общие сведения

* Команды и союзы создаются игроками напрямую через внутриигровые команды `/kklteams`.
* Все данные сохраняются в `kubejs/data/teams.json` (автоматически создаётся и обновляется).
* Игрок может состоять **только в одной команде** одновременно.
* Команда может состоять **только в одном союзе**.
* У каждой команды есть:
    * **Название** (уникальное)
    * **Владелец** (создатель)
    * **Участники**
    * **Точки интереса (POI)** - связанные игровые точки интереса.
    * **Союз** (опционально) - название союза, в котором состоит команда.

---

## 📋 Список доступных команд

| Команда | Назначение | Доступ |
|---------|------------|--------|
| `/kklteams create <имя>` | Создать новую команду | Все игроки |
| `/kklteams invite <ник>` | Пригласить игрока в свою команду | Только владелец |
| `/kklteams join <имя>` | Принять приглашение и вступить в команду | Игрок с приглашением |
| `/kklteams leave` | Покинуть текущую команду | Все участники, кроме владельца |
| `/kklteams kick <ник>` | Выкинуть игрока из команды | Только владелец |
| `/kklteams rename <новое_имя>` | Переименовать свою команду | Только владелец |
| `/kklteams disband` | Распустить свою команду полностью | Только владелец |
| `/kklteams list` | Посмотреть список всех команд | Все |
| `/kklteams info <имя>` | Посмотреть состав и точки команды | Все |
| **Союзы** | | |
| `/kklteams alliance create <имя>` | Создать новый союз | Только владелец команды |
| `/kklteams alliance invite <команда>` | Пригласить команду в союз | Только основатель союза |
| `/kklteams alliance join <имя>` | Принять приглашение и вступить в союз | Владелец команды с приглашением |
| `/kklteams alliance leave` | Покинуть союз | Владелец команды в союзе |
| `/kklteams alliance rename <имя>` | Переименовать союз | Только основатель союза |
| `/kklteams alliance list` | Посмотреть список всех союзов | Все |
| `/kklteams alliance info <имя>` | Посмотреть состав союза и команды-участники | Все |

## Подробное описание команд

### Создание команды

**Команда:**
```
/kklteams create <имя_команды>
```

Создаёт новую команду, если:
* имя ещё не занято;
* игрок не состоит в другой команде.

Создатель автоматически становится владельцем и первым участником.
**Поддерживает кириллицу и пробелы без кавычек!**

> Пример:
> `/kklteams create Северный Легион`
> `/kklteams create "Тёмные Всадники"` (кавычки необязательны)

---

### Приглашения в команду

**Команда:**
```
/kklteams invite <ник>
```

Отправляет приглашение выбранному игроку (он должен быть онлайн).
Приглашённый игрок получит сообщение и сможет принять приглашение через `/kklteams join`.
При вводе команды появляется список онлайн-игроков для удобного выбора.

> Приглашать может только **владелец команды**.

---

### Присоединение к команде

**Команда:**
```
/kklteams join <имя_команды>
```

Позволяет вступить в команду, если:
* игрок получил приглашение от этой команды;
* он ещё не состоит в другой команде.

После вступления приглашение удаляется.

---

### Выход из команды

**Команда:**
```
/kklteams leave
```

Позволяет покинуть команду.

> Если игрок является **владельцем**, нужно использовать `/kklteams disband`.

### ️ Исключение из команды

**Команда:**
```
/kklteams kick <ник_игрока>
```

Позволяет **владельцу команды** исключить участника.
Игрок будет немедленно удалён из состава команды и потеряет доступ к её точкам интереса.
При вводе команды появляется список членов команды для выбора.

> Использовать команду может **только владелец**.

---

### Переименование команды

**Команда:**
```
/kklteams rename <новое_имя>
```

Позволяет владельцу изменить название команды.
Автоматически обновляет все связи:
* В союзах (если команда - основатель)
* В приглашениях и членстве

---

### Роспуск команды

**Команда:**
```
/kklteams disband
```

Удаляет команду полностью, если её вызывает владелец.
Особенности:
* Если команда - **основатель союза**, союз распускается полностью
* Если команда - **участник союза**, она просто покидает союз
* Все участники автоматически исключаются
* Все привязанные точки освобождаются

---

## Система союзов

Союзы позволяют объединить несколько команд для:
* Совместного доступа к точкам интереса (шахты, статуи пиглинов)
* Стратегического взаимодействия на сервере

### Создание союза

**Команда:**
```
/kklteams alliance create <название>
```

Создаёт новый союз, если:
* игрок владеет командой;
* команда не состоит в другом союзе;
* название союза свободно.

Создатель автоматически становится основателем союза.

> Пример:
> `/kklteams alliance create Альянс Света`
> `/kklteams alliance create "Тёмная Орда"` (кавычки необязательны)

---

### Приглашения в союз

**Команда:**
```
/kklteams alliance invite <команда>
```

Позволяет **основателю союза** пригласить команду.
Владелец приглашённой команды получит сообщение с инструкцией.
При вводе команды появляется список команд для удобного выбора.

---

### Присоединение к союзу

**Команда:**
```
/kklteams alliance join <название>
```

Позволяет владельцу команды присоединиться к союзу, если:
* команда получила приглашение;
* команда не состоит в другом союзе.

---

### Выход из союза

**Команда:**
```
/kklteams alliance leave
```

Позволяет владельцу команды покинуть союз.

> Если команда - **основатель союза**, нужно использовать `/kklteams disband` для роспуска команды.

---

### Переименование союза

**Команда:**
```
/kklteams alliance rename <новое_имя>
```

Позволяет основателю изменить название союза.
Автоматически обновляет все связи в данных.

## Просмотр информации

### 📋 Список команд

**Команда:**
```
/kklteams list
```

Показывает все существующие команды и количество участников в каждой.

Пример вывода:
```
Список команд:
- Северный Легион [3 игроков]
- Тёмные Всадники [5 игроков]
```

---

### ℹ️ Информация о команде

**Команда:**
```
/kklteams info <имя_команды>
```

Отображает подробную информацию:
* владельца,
* участников,
* привязанные точки интереса (POI),
* союз (если есть).

Пример вывода:
```
Инфо о команде Северный Легион:
Владелец: Masonhades_
Участники: Masonhades_, Player2, Player3
Точки: mine_1, pig_3
Союз: Альянс Света
```

---

### 🌐 Список союзов

**Команда:**
```
/kklteams alliance list
```

Показывает все существующие союзы и количество команд в каждом.

Пример вывода:
```
Список союзов:
- Альянс Света [2 команд]
- Тёмная Орда [3 команд]
```

---

### 📋 Информация о союзе

**Команда:**
```
/kklteams alliance info <название>
```

Отображает подробную информацию:
* основателя (команду),
* команды-участники,
* количество игроков в союзе.

Пример вывода:
```
Союз: Альянс Света
Основатель: Северный Легион
Команды:
- Северный Легион (3 игроков)
- Стальные Щиты (4 игроков)
```
