# Острова

В начале игры вы появитесь на одном из **4 уникальных парящих островов**. Каждый остров имеет свои особенности, преимущества и недостатки.

На каждом острове расположена **бесконечная жила одного из основных металлов**, поэтому выбор острова влияет на доступные вам ресурсы и делает каждый остров по-своему ценным.

> **Важно:** сменить остров для спавна можно только **1 раз**.

Для смены острова используйте команду:

```text
/island <цифра острова>
```

Например:

```text
/island 1
```

## Список островов

* 🌊 **Морской остров**
* 🌋 **Вулканический остров**
* 🌲 **Лесной остров**
* 🏜️ **Пустынный остров**

Каждый остров отличается своим окружением и доступными ресурсами, поэтому перед выбором стоит учитывать его особенности.

## Что находится за пределами островов?

В **самом центре карты** находится отдельный остров из **эндерняка**.

А по краям карты, за пределами основных островов, расположены **острова Ада**.

Таким образом, карта разделена на несколько крупных зон:

* основные парящие острова;
* центральный остров из эндерняка;
* острова Ада по краям карты.

Это делает **Aeronautics** не просто красивым дополнением, а действительно **необходимым инструментом для перемещения между различными частями мира**.
