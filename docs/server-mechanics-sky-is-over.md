# ⚙️ Механики Sky Is Over

**Sky Is Over** - межсезонье, посвящённое исследованию возможностей **Aeronautics** и жизни в мире, разделённом на парящие острова.

Игрокам предстоит осваивать летающие аппараты, перемещаться между островами и добывать ограниченные виды ресурсов, используя уникальную систему залежей.

---

## 🧭 Основные механики

| Механика                        | Краткое описание                                                                                                                                  |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| [**Острова**](/sky-is-over-islands)         | Четыре уникальных парящих острова, каждый со своими особенностями и бесконечной залежью одного из основных ресурсов.                              |
| [**Аэронавтика**](/sky-is-over-aeronautics) | Основная механика межсезонья. Стройте летающие аппараты и используйте их для перемещения между островами и исследования мира.                     |
| [**Ресурсы**](/sky-is-over-resources)       | Железо, золото, цинк и медь добываются из бесконечных залежей с помощью специального бура. Каждый остров обладает своей основной ресурсной жилой. |

---

## Главная идея

**Sky Is Over** - это мир, где земля больше не является единственным способом передвижения.

Четыре парящих острова, центральный остров из эндерняка и острова Ада образуют единую систему территорий, между которыми предстоит путешествовать по воздуху.

**Стройте, исследуйте, добывайте ресурсы и оставьте небо позади.**
